Izbor's terminal app — the running Claude Code sessions, as Izbor observes them

  izbor                            Live: the sessions Izbor can observe. Starts Izbor in the background if none runs
  izbor --port 5000                Izbor on another port. Or the IZBOR_PORT variable. Default: 4319. PORT is never read
  izbor serve                      Izbor in this terminal, in front, like npm run dev. Ctrl-C stops it
  izbor serve --port 5000          Izbor on another port. Or the IZBOR_PORT variable
  izbor stop                       Stop Izbor: it asks first when a window listens. --yes asks nothing
  izbor status                     Whether Izbor runs, since when, its data folder and what it watches
  izbor status --disk-usage        Also count stored history's size; this walks the data folder
  izbor hooks [folder]             Adds Izbor's hooks to that project's .claude/settings.local.json. Default: this folder
  izbor hooks --remove [folder]    Removes them again
  izbor plugin [folder]            Turns acting on there: Izbor's plugin and its answer hook. Default: this folder
  izbor plugin --remove [folder]   Turns it off again
  izbor --version                  When npm run build last built this checkout, for bug reports
  In this checkout, npm run terminal runs the source; npm run dev runs Izbor from it

Click or Enter   Act on a line at once: open a Brief, start observing, or add hooks or the plugin
Tab / Shift-Tab  Next and previous line, then the side Brief, its field and Help
Up / Down        Move the focus; in an open Brief, scroll it
Enter on a Brief Put the cursor in its field
Ctrl-O           Switch Home and Sessions
Esc              Step back: field, Brief, Sessions, Home
Page Up / Down   Scroll the list or the Brief
Wheel/trackpad   Scroll the pane under the pointer
h                Hide the side Brief
m                Show or hide Metadata: the full ID, the Task, the sources, the exact times
s                Stop observing the open Brief's session; it keeps running
Ctrl-G           Open or close Help
Ctrl-C / Ctrl-D  Quit Izbor and restore your terminal

--port applies to the terminal app and to serve, stop, status, hooks and plugin.
For a folder that starts with a dash, use: izbor hooks -- -folder (or izbor plugin -- -folder).
--no-color, --no-mouse and --no-bell work only in the terminal app. --no-color disables styling.
--no-mouse leaves mouse gestures to your terminal, including text selection.
--no-bell turns off the bell, which rings when an observed session starts waiting or an answer is not taken.
At 140 columns × 20 rows, Sessions and Brief split 60/40 after padding.
Smaller usable windows open the Brief in the main view; Esc returns.
Below 40 columns or 12 rows, resize to resume. Selection and the field's text stay intact.
Hide keeps the selected session.
Each row starts with its Status glyph: ! waiting, * Working, ✓ Idle, ? Unknown, ▲ not live. Open › stands at the right edge of the focused row, else the selected one, not while its Brief is open beside the list.
